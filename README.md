# Stillgoing — Streak PWA

Installable, offline-capable streak tracker.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `manifest.json`, `sw.js`, and `icon.svg` to its root.
3. Open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Visit the published Pages URL on your phone.
5. iPhone: Safari Share → Add to Home Screen. Android: Chrome menu → Install app / Add to Home screen.

Streak data is stored locally in the browser/device. The day count includes the start date as day 1. Day-goal progress is based on calendar days and does not auto-end.
